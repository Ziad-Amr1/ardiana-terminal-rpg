# Ardiana Terminal RPG

A terminal-based RPG game built with Node.js and JavaScript.

This project started as a simple learning project, then gradually evolved into a modular RPG architecture experiment focused on:

- Backend thinking
- System design
- State management
- Game architecture
- Modular systems
- Save/load mechanics
- Turn-based combat
- Weighted enemy spawning
- Inventory & loot systems

---

## Current Features

- Turn-based battle system
- Area traversal system
- Encounter system
- Inventory system
- Loot/drop system
- EXP & leveling
- Save/load support
- Travel & movement mechanics
- Weighted spawning system
